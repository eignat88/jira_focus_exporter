При комплектации из волны система выбирает маркированную партию (ALK_ECMARKCODEAPPLIED = 1), хотя есть немаркированная (ALK_ECMARKCODEAPPLIED = 0).

Пример: Волна 000878572, заказ SO28585198, маршрут MK91576487 (можно отменить), номенклатура CLOR82794.

Требования:
- Для складов с InventLocation.ALK_ECON = Yes: сортировка ItemId -> ALK_ECMARKCODEAPPLIED ASC -> ExpDate -> AvailPhysicalLocation
- Для складов с ALK_ECON = No: без изменений

Тест: Отменить MK91576487, запустить комплектацию заново, проверить выбор партии.
