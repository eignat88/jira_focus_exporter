# Документация по мониторингу ключевых метрик WMS

## Назначение

Автоматизированный сбор и анализ метрик функционала КМ/ШК в WMS для:
- Контроля ошибок сканирования
- Мониторинга настроек маркировки
- Отслеживания конкуренции MP
- Оптимизации производительности

## 2. Метрики

### 2.1. Метрики ошибок

| Метрика | Источник | Формула | Частота |
|---------|----------|---------| Ежедневно |
| **Количество ошибок "Требуется КМ"** | `WMS_PickDiffActLine` | `COUNT(*) WHERE ActType = 'ProblemKM' AND Reason = 'NoScanMC'` | Ежедневно |
| **Доля успешных сканирований** | `WMS_JournalWarehouseOperationTable` | `COUNT(WHERE Success) / COUNT(*)` | Ежедневно |
| **Среднее время обработки ошибки** | `WMS_PickDiffActLine` | `AVG(DATEDIFF(Created, Resolved))` | Еженедельно |

### 2.2. Метрики настроек

| Метрика | Источник | Формула | Частота |
|---------|----------|---------| Ежедневно |
| **Доля ТГ с ALK_ScanMC=Да** | `MPProductGroup` | `COUNT(WHERE ALK_ScanMC=Yes) / COUNT(*)` | Еженедельно |
| **Доля ОСУ с EnableWithoutMC=Да** | `MPProductGroupFEACCMarkDates` | `COUNT(WHERE EnableWithoutMC=Yes) / COUNT(*)` | Ежедневно |
| **Настройки с истёкшим сроком** | `MPProductGroupFEACCMarkDates` | `COUNT(WHERE InternalForbidenTurnoverDate <= TODAY)` | Ежедневно |

### 2.3. Метрики конкуренции MP

| Метрика | Источник | Формула | Частота |
|---------|----------|---------| Ежедневно |
| **Количество конкурентных КМ** | `LFL_MarkingCodeTable` | `COUNT(*) WHERE Competitor = Yes` | Ежедневно |
| **Доля конкурентных КМ** | `LFL_MarkingCodeTable` | `COUNT(WHERE Competitor=Yes) / COUNT(*)` | Еженедельно |
| **Топ товаров с конкуренцией** | `LFL_MarkingCodeTable` | `GROUP BY ItemId ORDER BY COUNT(*) DESC` | Еженедельно |

### 2.4. Метрики статусов ГИС МТ

| Метрика | Источник | Формула | Частота |
|---------|----------|---------| Ежедневно |
| **Распределение статусов** | `ALK_MarkSerial` | `GROUP BY StatusExt` | Ежедневно |
| **КМ с недопустимыми статусами** | `ALK_MarkSerial` | `COUNT(WHERE StatusExt != 'INTRODUCED')` | Ежедневно |
| **Доля активных КМ** | `ALK_MarkSerial` | `COUNT(WHERE StatusExt='INTRODUCED') / COUNT(*)` | Еженедельно |

### 2.5. Метрики производительности

| Метрика | Источник | Формула | Частота |
|---------|----------|---------| Ежедневно |
| **Среднее время сканирования** | `LFL_PickingLineBufferMarking` | `AVG(DATEDIFF(ScanStart, ScanEnd))` | Ежедневно |
| **Количество сканирований в час** | `LFL_PickingLineBufferMarking` | `COUNT(*) / DATEDIFF(hours)` | Ежедневно |
| **Использование MD5-хеша** | `LFL_PickingLineBufferMarking` | `COUNT(WHERE MD5Hash != '') / COUNT(*)` | Еженедельно |

## 3. Настройка и запуск

### 3.1. SQL-скрипты

**Расположение:** `МЕТРИКИ_МОНИТОРИНГА.sql`

**Запуск:**
```sql
-- Через SQL Server Management Studio
-- Или через пакетный файл:
sqlcmd -S <server> -d <database> -i МЕТРИКИ_МОНИТОРИНГА.sql -o report.txt
```

**Параметры:**
- Измените `DATEADD(day, -7, GETDATE())` на нужный период
- Добавьте фильтры по складу/организации при необходимости

### 3.2. X++ класс

**Расположение:** `XPP_КЛАСС_МОНИТОРИНГА.xpp`

**Регистрация:**
1. Создайте Job в AOT: `Jobs → ALK_WMS_MetricsCollector`
2. Настройте расписание (Ежедневно, 02:00)
3. Укажите email получателя

**Параметры запуска:**
```
Тип метрик: All | ErrorCount | ProblemKM | CompetitorMP | SettingsAudit | Performance
Период: [Дата начала] - [Дата окончания]
Отправить email: Да/Нет
Email: admin@company.com
```

### 3.3. Пакетный файл (PowerShell)

```powershell
# run_metrics_collector.ps1
param(
    [string]$Server = "wms-db-server",
    [string]$Database = "WMS_DB",
    [string]$ReportPath = "C:\Reports\WMS_Metrics"
)

$date = Get-Date -Format "yyyyMMdd"
$outputFile = "$ReportPath\metrics_$date.sql"

# Запуск SQL-скрипта
sqlcmd -S $Server -d $Database -i "МЕТРИКИ_МОНИТОРИНГА.sql" -o $outputFile

# Отправка по email (если настроен)
if ($SendEmail) {
    Send-MailMessage -To "admin@company.com" `
        -Subject "WMS Метрики $date" `
        -Body "Отчёт прикреплён" `
        -Attachments $outputFile `
        -SmtpServer "smtp.company.com"
}

Write-Host "Отчёт сохранён: $outputFile"
```

## 4. Алерты

### 4.1. Критичные алерты

| Алерт | Условие | Действие |
|-------|---------|----------|
| **EnableWithoutMC истекает** | `InternalForbidenTurnoverDate <= TODAY + 7 дней` | Отключить `EnableWithoutMC` |
| **Заблокированные КМ в активных заданиях** | `Blocked=Yes AND PickedQty < Qty` | Проверить задание |
| **>3 конкурентов на товар** | `COUNT(DISTINCT ExtOwnerName) > 3` | Проверить поставщиков |

### 4.2. Предупреждения

| Алерт | Условие | Действие |
|-------|---------|----------|
| **ALK_ScanMC без шаблона** | `ALK_ScanMC=Yes AND ALK_MPCisTemplate IS NULL` | Настроить шаблон КМ |
| **>10% проблемных КМ** | `ProblemKM / Total > 0.1` | Проверить качество КМ |
| **Среднее время > 30 мин** | `AVG(processing_time) > 30` | Оптимизировать процесс |

### 4.3. Информационные

| Алерт | Условие | Действие |
|-------|---------|----------|
| **Ежедневный отчёт** | Всегда | Отправить email |
| **Еженедельная сводка** | Понедельник | Отправить PDF-отчёт |

## 5. Отчёты

### 5.1. Ежедневный отчёт

**Содержание:**
- Количество сканирований (КМ, ШК, SSCC)
- Количество ошибок по типам
- Проблемные КМ по заданиям
- Конкуренция MP (топ-5 товаров)

**Формат:** Текстовый (email) + CSV (для Power BI)

### 5.2. Еженедельный отчёт

**Содержание:**
- Динамика метрик за неделю
- Анализ настроек (alk_ScanMC, EnableWithoutMC)
- Производительность сотрудников
- Рекомендации по оптимизации

**Формат:** PDF + Excel

### 5.3. Ежемесячный отчёт

**Содержание:**
- Сравнение с предыдущим месяцем
- Тренды по ключевым метрикам
- ROI доработок (DAX-008712...DAX-012371)
- Планы на следующий месяц

**Формат:** PowerPoint + Excel
