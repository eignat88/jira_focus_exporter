---

## 2. Инженерия признаков (День 3-5)

| Признак | Формула | Назначение |
|---------|---------|------------|
| `scan_interval` | `timestamp[i] - timestamp[i-1]` | Слишком быстрые сканы |
| `error_streak` | Счётчик подряд идущих ошибок | Нарушение процесса |
| `scans_per_hour` | `COUNT(scans) / часы работы` | Эффективность |
| `error_rate` | `errors / total_scans` | Качество |
| `competitor_ratio` | `competitor_km / total_km` | Проблемы с поставщиком |
| `time_since_last_scan` | `now - last_scan` | Простой |

---

## 3. Разметка данных (День 5-6)

- Правила для синтетических аномалий (если реальных мало)
- Пороговые значения для каждого типа аномалий:
  - Интервал < 2 сек → аномалия типа 1
  - > 5 ошибок подряд → аномалия типа 2
  - Рост конкурентных > 30% → аномалия типа 3

---

## 4. Обучение моделей (День 7-10)

| Модель | Когда использовать | Сложность |
|--------|-------------------|-----------|
| **Isolation Forest** | Быстрый старт, точечные выбросы | Низкая |
| **LOF** | Локальные кластеры аномалий | Средняя |
| **Autoencoder** | Сложные нелинейные паттерны | Высокая |
| **LSTM Autoencoder** | Временные зависимости | Очень высокая |

**Рекомендация:** Начать с Isolation Forest → потом добавлять сложные модели.

---

## 5. Валидация и метрики (День 11-12)

```
Precision = TP / (TP + FP)  → минимум ложных срабатываний
Recall    = TP / (TP + FN)  → минимум пропущенных аномалий
F1        = 2 * (P * R) / (P + R)  → баланс
FPR       = FP / (FP + TN)  → допустимый уровень шума
```
