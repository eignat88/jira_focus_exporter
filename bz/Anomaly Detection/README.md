# Обнаружение аномалий в сканировании марок

Система выявления подозрительных паттернов сканирования для предотвращения мошенничества и контроля качества работы сотрудников.

## Типы аномалий

| # | Аномалия | Описание |
|---|----------|----------|
| 1 | Слишком быстрое сканирование | Интервал < 2 сек |
| 2 | Много ошибок подряд | > 5 ошибок подряд |
| 3 | Увеличение конкурентных КМ | Рост > 30% |
| 4 | Отсутствие сканирований | Нет активности в рабочее время |
| 5 | Несоответствие SSCC | SSCC не найден в базе |

## Установка

```bash
pip install -r requirements.txt
```

## Использование

1. Подготовить данные в `data/raw/`
2. Запустить pipeline обработки
3. Обучить модели
4. Получить аномалии

## Модели

- **Isolation Forest** — точечные аномалии
- **LOF** — локальные аномалии
- **Autoencoder** — сложные паттерны
- **LSTM Autoencoder** — временные аномалии
